# 应用内多语言切换（In-App Language Switch）

本示例演示如何在涂鸦业务包 Demo（`bizsdk_sample`）中实现**应用内多语言切换**：不依赖系统语言设置，由 App 自行切换语言、持久化选择，并在重启后依然生效。

> 示例代码位于 `bizsdk_sample/app` 模块（源码包名 `com.tuya.appbizsdk.sample`）。

---

**核心机制**：通过更新 Application 级别 `Resources` 的 `Configuration.locale`，再用 `updateConfiguration(...)` 让资源按新语言刷新。
**持久化**：用户选择，App 重启后仍生效；

---

## 二、实现说明（bizsdk_sample）

### 1. `LocaleHelper` —— 核心工具类

路径：[bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/language/LocaleHelper.kt](../bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/language/LocaleHelper.kt)

提供三个对外能力：

| 方法 | 作用 | 对应 SDK |
| --- | --- | --- |
| `switchLanguage(context, language)` | 持久化语言 + 立即更新 App 级资源 | `ThingLanguageUtils.switchLanguage` |
| `wrap(context)` | 用持久化的语言包装 Context，供 `attachBaseContext` 调用 | —— |
| `getLanguage(context)` | 读取当前持久化的语言 | —— |

关键代码：

```kotlin
@Suppress("DEPRECATION")
fun switchLanguage(context: Context, language: String) {
    saveLanguage(context, language)                       // ① 持久化

    val res = context.applicationContext.resources
    val config = Configuration(res.configuration)
    applyLocale(config, resolveLocale(context, language)) // ② 设置 locale
    res.updateConfiguration(config, res.displayMetrics)   // ③ 刷新资源（同 SDK）
}
```

支持的语言常量（可按需扩展）：

```kotlin
const val LANG_SYSTEM = ""   // 跟随系统
const val LANG_ENGLISH = "en"
const val LANG_CHINESE = "zh"
```

> `LANG_SYSTEM`（跟随系统）会读取 `Resources.getSystem()` 的真实系统语言，不受 App 自身的覆盖影响。

### 2. `BaseActivity` —— 让页面生效

路径：[bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/language/BaseActivity.kt](../bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/language/BaseActivity.kt)

```kotlin
abstract class BaseActivity : AppCompatActivity() {
    override fun attachBaseContext(newBase: Context) {
        super.attachBaseContext(LocaleHelper.wrap(newBase))
    }
}
```

凡是需要支持语言切换的页面，把父类从 `AppCompatActivity` 改成 `BaseActivity` 即可。

> 说明：`bizsdk_sample/app` 模块里只有 `MainActivity` 这一个 Activity；其余页面（如登录页 `SplashActivity`、家庭管理、配网、场景、设备列表等）来自业务包/库，不在本模块源码中，它们会通过下面 `TuyaSmartApp` 的应用级注入拿到当前语言。

### 3. `TuyaSmartApp` —— 应用级注入

路径：[bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/TuyaSmartApp.kt](../bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/TuyaSmartApp.kt)

```kotlin
override fun attachBaseContext(base: Context) {
    super.attachBaseContext(LocaleHelper.wrap(base))  // App 重启后语言依旧生效
}
```

保证 App 重启（进程重建）后，资源也按持久化的语言加载；同时让库内页面也能跟随。

### 4. 调用示例 —— 切换入口

路径：[bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/main/MainActivity.kt](../bizsdk_sample/app/src/main/java/com/tuya/appbizsdk/sample/main/MainActivity.kt)

主页（`MainActivity`）「Language / 语言」入口，点击弹出单选列表，选择后切换并 `recreate()` 当前页面：

```kotlin
private fun showLanguageDialog() {
    val options = arrayOf(
        LocaleHelper.LANG_ENGLISH to getString(R.string.language_en),
        LocaleHelper.LANG_CHINESE to getString(R.string.language_zh),
        LocaleHelper.LANG_SYSTEM to getString(R.string.language_system)
    )
    val labels = options.map { it.second }.toTypedArray()
    val checkedItem = options.indexOfFirst { it.first == LocaleHelper.getLanguage(this) }

    AlertDialog.Builder(this)
        .setTitle(R.string.language_dialog_title)
        .setSingleChoiceItems(labels, checkedItem) { dialog, which ->
            val selected = options[which].first
            dialog.dismiss()
            LocaleHelper.switchLanguage(this, selected)  // 持久化 + 刷新资源
            recreate()                                   // 刷新当前页面 UI
        }
        .setNegativeButton(android.R.string.cancel, null)
        .show()
}
```

### 5. 字符串资源

`values/strings.xml`（英文，默认）与 `values-zh/strings.xml`（中文）新增：

```xml
<string name="language_setting">Language</string>           <!-- 语言 -->
<string name="language_dialog_title">Select Language</string><!-- 选择语言 -->
<string name="language_en">English</string>
<string name="language_zh">简体中文</string>
<string name="language_system">Follow System</string>       <!-- 跟随系统 -->
```

布局：[bizsdk_sample/app/src/main/res/layout/activity_main.xml](../bizsdk_sample/app/src/main/res/layout/activity_main.xml) 中新增 `language` 入口（`TextView`，与其它业务入口同款）。

> 注意：本模块生成的 `R` 类位于 namespace `com.thing.appbizsdk.sample`（与源码包名 `com.tuya.appbizsdk.sample` 不同，见 `app/build.gradle` 的 `namespace`）。代码里直接用 `R.string.xxx` / `getString(...)` 即可，无需关心二者差异。

## 三、如何使用

1. **运行 bizsdk_sample**，登录后进入主页（`MainActivity`）。
2. 点击列表中的「**Language / 语言**」入口（`binding.language`）。
3. 在弹窗中选择 **English / 简体中文 / 跟随系统**，页面会立即刷新为新语言。
4. **杀掉进程后重新打开**，所选语言依然生效（由 `SharedPreferences` 持久化 + `attachBaseContext` 注入）。

### 在你自己的代码里调用

```kotlin
// 切换为中文
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_CHINESE)
activity.recreate()                  // 刷新当前页面

// 切换为英文
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_ENGLISH)
activity.recreate()

// 跟随系统
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_SYSTEM)
activity.recreate()

// 读取当前选择（"" 表示跟随系统）
val lang = LocaleHelper.getLanguage(context)
```

> 新增语言选项需同时：① 在 `LocaleHelper` 增加常量并映射到对应 `Locale`；② 在 `values-<语言>/` 目录补充字符串资源。

---

## 四、新增语言步骤（示例：日语）

1. 在 `LocaleHelper` 增加：
   ```kotlin
   const val LANG_JAPANESE = "ja"
   // resolveLocale(...) 中：
   LANG_JAPANESE -> Locale.JAPANESE
   ```
2. 新建资源目录 `bizsdk_sample/app/src/main/res/values-ja/strings.xml`，翻译所需文案。
3. 在弹窗 `options` 中追加 `LocaleHelper.LANG_JAPANESE to getString(R.string.language_ja)` 选项。
4. 确保所在 Activity 继承自 `BaseActivity`，切换后调用 `recreate()`。
